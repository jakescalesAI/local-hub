# Brand marks

These files are only used in the browser demo of LocalHub TV, to stand in for apps that aren't
installed; on a TV every tile shows the app's own icon. Every mark here is a trademark of its owner.
They are used only to identify the apps, and using them doesn't mean those companies endorse
LocalHub.

## Tile glyphs

`<icon>.svg` (`netflix.svg`, `plex.svg` and so on) come from [Simple Icons](https://simpleicons.org)
(CC0 1.0).

## Wordmarks

`<id>-wordmark.svg` is the app's long logo, shown in white as the header when the app is focused.
Each one was taken from the source below and reduced to a single-colour path set (fill `#000`, no
background, viewBox cropped to the artwork) so it can be drawn as a CSS mask. Where the logo has a
second colour inside the first (YouTube's play triangle), that part is cut out; otherwise the
artwork is unchanged unless the table says so. Wikimedia Commons lists these files as public domain
because they are simple text logos, with a note that they are trademarked.

Before you start

LocalHub doesn’t install anything else for you. Chat needs Claude Code, and reaching LocalHub from other devices needs Tailscale. You get both from their own sites.

If you want other devices, install Tailscale first. You choose who can reach LocalHub during setup.

1Install

LocalHub’s desktop app is for Windows only for now.

  1. Get the installer from the home page.
  2. Open the file you downloaded. It installs for your Windows user, with no admin prompt.
  3. The installer isn’t signed yet, so Windows SmartScreen may warn you. Choose More info, then Run anyway.
  4. LocalHub opens when it’s done. If it doesn’t, open it from the Start menu.

Closing the window keeps LocalHub running, with an icon in the tray by the clock. To stop it, click that icon and choose Quit. Uninstalling leaves your settings and keys on the computer.

2First run

The first time it opens, LocalHub asks four things.

A name

Call your hub anything, or keep “LocalHub”.

Who can reach it

Only this computer is the safe default. Nothing else can open LocalHub.

My tailnet also lets your own devices on Tailscale open it, with a passcode. A tailnet is your private Tailscale network. This option stays grey until Tailscale is installed on this computer. Part 5 has the steps.

The screen says you can widen this later, but there’s no screen for changing it after setup yet, so choose with that in mind.

Connect Claude

This screen tells you whether Claude Code is installed and signed in. If it isn’t, you can still finish. Chat waits until it is, and part 3 shows how. Leave Claude folder empty.

Optional keys

You can skip all of these and press Finish. Each one turns on an extra tab, and none of them are needed for Chat. They stay on this computer.

3The assistant

Chat runs through Claude Code, Anthropic’s own program, on your computer and with your own account. LocalHub never sees your password.

Anthropic says its free plan doesn’t include Claude Code, so you’ll need a paid Claude plan or an Anthropic Console account.

  1. Install Claude Code by following Anthropic’s install page.
  2. Open a terminal, which is a window where you type commands. Press the Windows key, type PowerShell and press Enter.
  3. Type claude and press Enter. Your browser opens so you can sign in.
  4. Close the terminal and go back to LocalHub’s Chat tab.

LocalHub can run Chat on an Anthropic API key instead of a login, but Claude Code still has to be installed, and there’s no screen for adding that key yet. The OpenRouter and DeepSeek keys in setup don’t run Chat.

4The launcher

Press Ctrl Alt Space anywhere in Windows and a small search bar opens over whatever you’re doing. Press Esc or click away to close it. Inside LocalHub’s own window, the search bar is Ctrl K.

To use different keys, click the tray icon and choose Settings, click in the Launcher hotkey box, press the keys you want and choose Save.

The launcher only works while LocalHub is running. To have it ready after a restart, turn on Start at login in the tray menu. It’s off until you do.

5Your other devices

Tailscale is a separate service that puts your own devices on one private network, and it has a free personal plan. LocalHub uses it to reach your PC from your other devices.

  1. Install Tailscale on this PC and sign in.
  2. Install Tailscale on the other device and sign in with the same account.
  3. In LocalHub’s first-run setup, choose My tailnet and set a passcode of at least 8 characters. If the option is still grey, quit LocalHub from the tray and open it again.
  4. Find this PC’s Tailscale address on the Machines page of Tailscale’s admin console. It looks like 100.x.y.z.
  5. On the other device, open a browser and go to http://100.x.y.z:3100 with your own address in it. Enter your passcode. That browser stays signed in for 30 days.

Keep it off the open internet

Never use Tailscale Funnel with LocalHub, and never put LocalHub on the open internet in any other way. Funnel opens a service on your computer to the wider internet, and LocalHub can see your files and act in your browser.

Already finished setup with Only this computer? There’s no screen for changing it yet.

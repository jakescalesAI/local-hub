LocalHub's page is built on these open components. Each was ported to plain JavaScript and CSS and changed for this page.

Glass reveal (glass.js)
  Glass icon reveal by Zanwei Guo. MIT. Full text in LICENSE-glass-icon-reveal.txt.

Chrome ribbons (ribbons.js)
  shader-metal by jay sharma (radiumcoders).
  https://21st.dev/@radiumcoders/components/shader-metal

Screenshot wall
  tilted-grid-hero by Ruixen.
  https://21st.dev/@ruixen.ui/components/tilted-grid-hero

Features orbit
  ink-orbit-features by Kedhareswer Naidu.
  https://21st.dev/@kedhareswer/components/ink-orbit-features

Polished chrome buttons (metal.js)
  Started from liquid-metal by Edu Calvo (SmoothUI), since rewritten; none of its surface code remains.
  https://21st.dev/@educalvolpz/components/liquid-metal
  https://github.com/educlopez/smoothui/blob/main/LICENSE

Note on these licences, to review before going live:
  The MIT terms for shader-metal, tilted-grid-hero and ink-orbit-features come from the "License: mit" field on
  their 21st.dev listings. No licence file from the author was found for any of the three.

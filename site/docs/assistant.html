The assistant

Ask in plain words, from any tab. It can look things up, change your Home and work in the browser.

What it needs

The assistant runs through Claude Code, Anthropic’s own program, on your computer and with your own account. That needs a paid Claude plan or an Anthropic Console account, because Anthropic says its free plan doesn’t include Claude Code.

LocalHub doesn’t install Claude Code for you. Getting started has the steps.

What you ask goes to Anthropic through Claude Code, under your account and its terms.

Use it

The ask bar sits at the bottom of every tab. Type there, or pick Ask chat in search. Chat opens in a panel, with New chat and Chat history at the top.

The + button holds the rest.

Attach files
Up to 5 files, up to 10 MB each.
Model, Effort
Which Claude model answers, and how hard it thinks.
Mode
Auto can act. Plan takes away every tool that changes anything, for that message.
Dictate
Talk instead of typing, where the window supports it. It says why when it can’t.
Full screen
Or press Ctrl /.

What it can do

  • Read files in your home folder and LocalHub’s own folder, except files that hold keys or passwords.
  • Write new files in LocalHub’s workspace folder, and move, copy, rename or bin files inside it.
  • Search the web.
  • Change your look and Home. Ask for it in plain words, and say “undo that” if you don’t like it.
  • Open a site as a card in the chat, and work in the Browser.

It has no command line and no tool that deletes outright. There’s no screen for changing what it can read and write yet.

When it stops and asks

Out of the box, before it sends, posts, buys, deletes or accepts terms for you, a card in the chat asks you to allow it. Only the card’s Allow counts, not typing yes. It’s good for that one action, and it lapses after 5 minutes.

  • It doesn’t type passwords, card numbers or two-factor codes. It hands the browser to you.
  • On social sites the last Post or Share click is yours. LocalHub refuses it from the assistant.
  • Text on a page or in a file counts as information, not as orders.

Two limits to know about

A copy of a key file can be read. LocalHub spots key files by name and place. If you copy one and give it an ordinary name, the assistant can read the copy.

A web page could try to steer it. Nothing in its tools stops a page from talking it into sending along the text of a file. Only the model’s own judgement does. Keep an eye on it on sites you don’t trust.

Messages you might see

The assistant needs Claude Code.
It isn’t installed, or LocalHub can’t find it. See Troubleshooting.
Claude is still answering in this chat.
Wait for the answer, or start a new chat.
Too many answers running at once. Try again in a moment.
Up to 3 can run together.
Claude usage limit reached.
You’ve reached your Claude plan’s limit. Try again after it resets.
This holds keys, so the hub won’t show it.
That’s on purpose. Attached files with names like that are left out too.

Troubleshooting

What can go wrong, in the words LocalHub uses, and what to do about it.

Starting up

Windows protected your PC

The installer isn’t signed yet, so SmartScreen may warn you. Choose More info, then Run anyway.

Your Hub did not start

It didn’t open its port after three tries, so the app stopped trying. The log is %APPDATA%\LocalHub\logs\hub.log. Press Try again.

Your Hub is not answering

It started but isn’t responding. Press Try again, and look in the same log if it keeps happening.

Port in use

Another program is using LocalHub’s port. Close it, or click the tray icon, choose Settings and pick another Hub port.

Waiting for your Hub

Nothing is answering on the port. The page reconnects by itself when LocalHub is back, or press Start the built-in Hub.

Restarting your Hub

It stopped unexpectedly, and the app is starting it again. You don’t need to do anything.

First-run setup

My tailnet is grey

Tailscale isn’t installed on this computer, or LocalHub looked before it was. Install it, quit LocalHub from the tray and open it again.

Setup only runs from this computer

Finish setup on the PC running LocalHub, not from another device.

I chose Only this computer and now want other devices

There’s no screen for changing it yet.

Search and the launcher

… isn’t available. It may be invalid or in use by another app.

Those keys are taken, so the app kept the ones that were working. Try a different set in Settings.

The full launcher isn’t available from your Hub yet.

The launcher couldn’t get its full page from LocalHub, so it offers a plain box instead. Type a web address, or press Enter to open LocalHub.

The keys do nothing

The launcher only works while LocalHub is running. Check for the icon in the tray, and turn on Start at login there if you want it after every restart.

Chat

The assistant needs Claude Code.

Follow the steps to install it. Use Anthropic’s native installer, because LocalHub doesn’t find a copy installed with npm.

Claude Code is installed. Run claude in a terminal once to sign in.

Open PowerShell, type claude, press Enter and sign in with your browser.

Couldn’t start Claude Code: …

Claude Code is there but wouldn’t run. Run claude in PowerShell to see what it says.

Claude usage limit reached.

You’ve reached your Claude plan’s limit. Try again after it resets.

The assistant has the rest of its messages.

Browser

Chrome is not installed

Install Google Chrome, then try again.

Chrome exited at start (is this profile open in another Chrome?)

Close that window and try again.

Chrome did not open its debugging port

Chrome started but LocalHub couldn’t talk to it. Close the Browser pop-up and open it again.

Other devices

That passcode isn’t right

Check it and try again. After 5 wrong tries you’ll have to wait.

Too many tries. Wait 15 minutes.

That address is locked out for 15 minutes. Then try again.

This hub doesn’t answer to that name

Use the 100.x.y.z address from Your other devices, not the computer’s longer Tailscale name.

Files, links and calendar

Those pages list their own messages: Files, Links and snippets and Calendar.

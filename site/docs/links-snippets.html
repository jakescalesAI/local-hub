Links and snippets

Keep the places you go and the text you retype, and reach them from the search bar.

Add one

Open search and pick Add a link or Add a snippet.

Web link
A name and an http or https address.
Folder on this computer
A name and the folder’s full path.
Obsidian link
A name and an obsidian:// address that opens, searches or picks a vault.
Snippet
A name and up to 100 KB of text. You can also give it a keyword: one word with no spaces, to find it by in search.

Use them

Type part of the name and press Enter. A link opens. A snippet is copied, ready to paste. If LocalHub can’t reach the clipboard, it shows the text for you to copy yourself.

To change one, select it and press Ctrl E.

A folder link only opens on the computer running LocalHub. To show a web link’s icon, LocalHub asks that site for it.

Bring them in or take them out

In search, Export links and snippets saves them to a file. Import links and snippets takes a file like that, or pasted text in the same format.

  • Importing the same file twice adds nothing new.
  • Anything refused is listed with the reason.
  • Folder and Obsidian links only come in if you tick Also bring in folder and Obsidian links from this file. Leave it off for a file you didn’t make.

If it won’t save

Links can’t hold a user name or password
Take the name and password out of the address.
Only http and https links can be saved as web links
Check the start of the address.
Network paths can’t be saved; use a folder on this computer
A folder link has to be on this PC’s own drives.
That folder holds keys, so the hub won’t open it
LocalHub keeps folders of keys and passwords out of reach on purpose.
That file is from a newer version of the hub
Update LocalHub, then import it again.
The keyword is already in use
Each snippet needs its own keyword.
